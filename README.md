# 북로드 (Book ROAD)

**한 권의 길을 걷는 독서기록장** — 경기도 중·고등학생을 위한 자율 독서 웹 기록장입니다(기본 40일).
학생은 경기도교육청 전자도서관에서 책 한 권을 골라 끝까지 읽으며 날마다 기록하고 ‘오늘의 독서 완료’ 도장을 모은 뒤, 기록장 파일을 선생님의 제출 폴더(OneDrive·Google Drive)에 올립니다.

- **회원가입 없음 · 서버 저장 없음 · 데이터베이스 없음**
- 학급 설정은 링크(`#c=…`) 안에, 학생 기록은 학생 브라우저(localStorage)에만 저장됩니다.

## 페이지
| 파일 | 내용 |
|---|---|
| `index.html` | 학생 화면 (내 책 · 읽기 전 · 읽는 중 · 읽은 후 · 독후활동 · 마무리·제출) |
| `teacher.html` | 선생님용: 우리 반 링크·QR코드 만들기 |
| `collect.html` | 선생님용: 제출 파일 모아보기, CSV 저장 |
| `guide.html` | 사용 안내 · 개인정보 안내 · 자주 묻는 질문 |
| `core.js` | 공통 데이터(독후활동 19종, 평가 기준)와 진행 상태 계산 |

## 시작하기 (선생님)
1. `teacher.html`에서 학교·시작일·제출 링크·독후활동 방식을 정하고 **링크 만들기**
2. 링크나 QR코드를 학생에게 안내
3. 중간 점검일·마지막 날에 제출된 파일을 `collect.html`에 끌어다 놓기
